# Alvaria 2026-2036

Site estático do projeto escolar de governo fictício de Alvaria, desenvolvido em HTML, CSS e JavaScript sem dependências de build. A estrutura funciona na raiz de um repositório GitHub Pages.

## Publicar pelo GitHub Pages

O repositório já possui GitHub Pages configurado para publicar a branch `main` a partir da pasta raiz (`/`). Depois de revisar as alterações, um commit enviado para `main` atualiza o site público em:

<https://0xvaguin.github.io/site-alvaria/>

Para usar este conteúdo em outro repositório, acesse **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`. Não há etapa de compilação.

## Arquivos

- `index.html`: conteúdo em português e estrutura semântica da página.
- `assets/styles.css`: layout responsivo e identidade visual.
- `assets/script.js`: navegação recolhível em telas pequenas.
- `assets/mapa-alvaria.svg`: mapa esquemático original com localização indicativa das frentes de infraestrutura.
- `assets/insignia.svg` e `assets/bandeira-alvaria.svg`: interpretação visual dos símbolos e identidade do partido descritos nos documentos.
- `assets/images/composicao-social.png`: gráfico fornecido nos materiais do projeto.
- `assets/images/terracos-agricolas.webp`: fotografia ilustrativa encontrada na busca do Unsplash por "Banaue Rice Terraces" (<https://unsplash.com/s/photos/banaue-rice-terraces>). A foto mostra terraços em Banaue, nas Filipinas, e não representa Alvaria.

## Decisões de conteúdo

- O plano registra que a primeira ficha do PPLA cita o envelhecimento acelerado como prioridade. A ficha de Alvaria descreve a população como predominantemente jovem e adulta. O site explicita essa diferença e adapta a prioridade do governo para educação, qualificação e emprego, mantendo saúde preventiva e acessibilidade no programa.
- Os percentuais registrados para a classe média somam 85%. O site sinaliza a lacuna e não distribui os 15 pontos restantes por conta própria.
- O mapa não nomeia cidades nem representa distâncias reais, pois esses dados não constam nos documentos. Ele localiza apenas as regiões descritas e os investimentos propostos.
